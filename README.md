# ICE Nice

نسخهٔ به‌روزشدهٔ نمونهٔ بازی نقش‌آفرینی ژئوپلیتیکی ICE Nice.

## امکانات این نسخه
- ورود و ثبت‌نام بازیکن و ورود مالک با `ADMIN_USERNAME` و `ADMIN_PASSWORD`
- اعتبار اولیهٔ صفر برای حساب‌های جدید؛ موجودی بازیکنان از پنل مالک قابل تنظیم است
- فهرست ۲۰ ابرقدرت با پرچم، نام کامل فارسی و رتبهٔ قابل تغییر
- مدیریت افزودن/حذف آیتم‌های شاپ و قیمت‌ها از پنل مالک
- انتخاب کشور یا سازمان/گروه هنگام ثبت‌نام
- دیپلماسی دوجانبه: انتخاب کشور مقصد، ارسال پیشنهاد سیاسی/تجاری و امکان پذیرش یا رد توسط کشور مقصد
- نقشهٔ تعاملی نشانگرمحور با رنگ و وضعیت قابل تنظیم توسط مالک
- مهاجرت سادهٔ ستون‌های تازه برای پایگاه دادهٔ نسخهٔ قبلی

## استقرار در Render
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app`
- Environment variables:
  - `SECRET_KEY`: یک مقدار تصادفی و محرمانه
  - `ADMIN_USERNAME`: نام کاربری مالک
  - `ADMIN_PASSWORD`: رمز قوی مالک
  - `DATABASE_URL`: آدرس PostgreSQL پایدار؛ فایل `render.yaml` برای ساخت دیتابیس و اتصال آن تنظیم شده است. اگر سرویس فعلی‌ات از قبل به دیتابیس دیگری وصل است، قبل از استفاده از Blueprint این اتصال را بررسی کن.

در هر شروع برنامه، اگر حساب `ADMIN_USERNAME` از قبل وجود داشته باشد، نقش آن به مالک ارتقا پیدا می‌کند و گذرواژه‌اش با `ADMIN_PASSWORD` همگام می‌شود. این دو متغیر را محرمانه نگه دارید و آن‌ها را در مخزن GitHub قرار ندهید.

## نقشه
نقشهٔ این نسخه از کاشی‌های OpenStreetMap و Leaflet استفاده می‌کند و کشورهای دارای مختصات تعریف‌شده را با نشانگرهای رنگی نمایش می‌دهد. رنگ و وضعیت نشانگرها از پنل مالک تغییر می‌کند. بارگذاری نقشه به اتصال اینترنت مرورگر به سرویس‌های بیرونی وابسته است.

## نکتهٔ مهم دربارهٔ دیتابیس و حساب‌های قبلی
این نسخه از `DATABASE_URL` برای ذخیرهٔ پایدار اطلاعات پشتیبانی می‌کند. اضافه‌کردن دیتابیس PostgreSQL تازه به سرویس موجود به‌خودی‌خود حساب‌های ذخیره‌شده در SQLite قبلی را منتقل نمی‌کند؛ اگر حساب‌های قبلی هنوز در دیتابیس قبلی موجودند، پیش از سوییچ‌کردن اتصال باید از آن‌ها نسخهٔ پشتیبان/مهاجرت تهیه شود. اگر اطلاعات روی دیسک موقت Render قبلاً پاک شده باشند، این کد به‌تنهایی آن حساب‌ها را بازیابی نمی‌کند.

## استقرار امن نسخهٔ جدید
1. از مخزن و دیتابیس فعلی نسخهٔ پشتیبان بگیر.
2. فایل‌ها را در شاخهٔ پروژه جایگزین کن و commit کن.
3. اگر از Render Blueprint برای ساخت PostgreSQL استفاده می‌کنی، ابتدا بررسی کن دیتابیس جدیدی ساخته نشود که ناخواسته جای دیتابیس فعلی را بگیرد.
4. پس از تنظیم `DATABASE_URL` درست، استقرار را انجام بده و ثبت‌نام/ورود و ارسال پیشنهاد دیپلماتیک را آزمایش کن.
