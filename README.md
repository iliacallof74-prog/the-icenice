# ICE Nice

نسخهٔ به‌روزشدهٔ نمونهٔ بازی نقش‌آفرینی ژئوپلیتیکی ICE Nice.

## امکانات این نسخه
- ورود و ثبت‌نام بازیکن و ورود مالک با `ADMIN_USERNAME` و `ADMIN_PASSWORD`
- اعتبار اولیهٔ صفر برای حساب‌های جدید؛ موجودی بازیکنان از پنل مالک قابل تنظیم است
- فهرست ۲۰ ابرقدرت با پرچم، نام کامل فارسی و رتبهٔ قابل تغییر
- مدیریت افزودن/حذف آیتم‌های شاپ و قیمت‌ها از پنل مالک
- انتخاب کشور یا سازمان/گروه هنگام ثبت‌نام
- دیپلماسی با انتخاب طرف مقابل و فیلد جزئیات معاملهٔ تجاری
- نقشهٔ تعاملی نشانگرمحور با رنگ و وضعیت قابل تنظیم توسط مالک
- مهاجرت سادهٔ ستون‌های تازه برای پایگاه دادهٔ نسخهٔ قبلی

## استقرار در Render
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app`
- Environment variables:
  - `SECRET_KEY`: یک مقدار تصادفی و محرمانه
  - `ADMIN_USERNAME`: نام کاربری مالک
  - `ADMIN_PASSWORD`: رمز قوی مالک
  - `DATABASE_URL`: ترجیحاً آدرس پایگاه دادهٔ PostgreSQL پایدار در Render

در هر شروع برنامه، اگر حساب `ADMIN_USERNAME` از قبل وجود داشته باشد، نقش آن به مالک ارتقا پیدا می‌کند و گذرواژه‌اش با `ADMIN_PASSWORD` همگام می‌شود. این دو متغیر را محرمانه نگه دارید و آن‌ها را در مخزن GitHub قرار ندهید.

## نقشه
نقشهٔ این نسخه از کاشی‌های OpenStreetMap و Leaflet استفاده می‌کند و کشورهای دارای مختصات تعریف‌شده را با نشانگرهای رنگی نمایش می‌دهد. رنگ و وضعیت نشانگرها از پنل مالک تغییر می‌کند. بارگذاری نقشه به اتصال اینترنت مرورگر به سرویس‌های بیرونی وابسته است.
